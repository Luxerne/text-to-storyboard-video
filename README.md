# 文字转分镜与首尾帧

这是一个用于 Codex 的 Skill。它可以读取故事、脚本、旁白或场景描述，自动完成：

- 分析人物、场景和剧情节奏
- 生成完整的镜头分镜表
- 为每个镜头生成首帧和尾帧图片
- 保持人物、服装、道具、光线和画风一致
- 根据实际首尾帧生成图生视频提示词
- 汇总可直接复制到视频生成工具中的提示词

## 安装方法

把这个 GitHub 仓库链接发给 Codex，然后说：

```text
请帮我安装这个 GitHub 仓库里的 Skill：
【粘贴仓库链接】
```

也可以下载仓库 ZIP，解压后将整个 `text-to-storyboard-video` 文件夹放入：

```text
Windows：C:\Users\你的用户名\.codex\skills\
macOS / Linux：~/.codex/skills/
```

安装后建议重新启动 Codex，或新建一个会话。

## 使用方法

在 Codex 中输入：

```text
使用 $text-to-storyboard-video 处理下面这段文字：

雨夜，一名穿黄色雨衣的女孩站在旧车站前。末班车缓缓驶来，
但车厢里空无一人。女孩犹豫片刻，最终走向打开的车门。
```

你也可以补充自己的要求：

```text
使用 $text-to-storyboard-video 把下面的故事制作成分镜、首尾帧图片和图生视频提示词。

画面风格：日系动画
画幅：9:16
单个镜头时长：5秒
整体氛围：温暖、治愈

故事：
【粘贴你的文字】
```

## 默认设置

如果没有特别说明，Skill 将采用：

- 电影写实风格
- 16:9 画幅
- 24 fps
- 每个镜头约 4–6 秒
- 根据故事节奏自动决定镜头数量
- 自动避免画面中出现无关文字

## 输出内容

执行后会依次得到：

1. 创作假设和人物、场景一致性设定
2. 分镜总览
3. 每个镜头的首帧图片及提示词
4. 每个镜头的尾帧图片及提示词
5. 连接首尾帧的图生视频提示词
6. 方便批量复制的提示词汇总

## 注意事项

- 图片生成效果取决于当前 Codex 环境是否提供图片生成能力。
- 镜头较多时会生成较多图片，处理时间也会增加。
- 如果角色外观非常重要，建议在请求中详细描述人物的年龄、发型、服装和显著特征。
